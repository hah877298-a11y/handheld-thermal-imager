# 主板打样与工艺说明

版本 v1.4　导出日期 2026-11-17

## 一、板卡概述

| 项目 | 内容 |
|---|---|
| 主控 | STM32F103ZET6（LQFP-144，嘉立创 C8310） |
| 供电 | USB Type-C 16P 母座（仅供电，C165948）→ F1 自恢复保险丝 0.5A → AMS1117-3.3（C498117）→ 3.3V |
| Type-C 配置 | CC1、CC2 各经 5.1k 下拉（R12、R13），D+/D- 悬空并加非连接叉，不做 USB 数据 |
| 显示 | 2.54mm 2×17 排母（LCD1），直插 ATK-MD0280 2.8 寸并口屏 |
| 存储 | TF 卡座 TF1（推拉式，C293569） |
| 人机 | 4 个轻触按键 SW1~SW4、2 个 LED、5V 有源蜂鸣器 LS1（Q1 SS8050 驱动） |
| 时钟 | 8MHz 主晶振 Y1 + 32.768kHz RTC 晶振 Y2 |
| 保护与滤波 | D1 1N4148、L1 磁珠、F1 自恢复保险丝、C16/C19 储能 |
| 调试 | J1（5P）SWD + 串口，J2/J3（4P）备用 IO |

说明：上一版的 Micro-B 座与 D2（USBLC6-2SC6）已删除，改为纯供电 Type-C 接口，Type-C 只取 5V，不参与通信，程序下载与调试仍走 J1 的 SWD。

## 三、DRC 与自检结果

- PCB DRC：0 错误 0 违规，连续运行两次结果一致（本轮修改后重新校验）。
- 规模：58 个器件 / 334 个焊盘 / 93 个过孔 / 906 条走线 / 61 个网络 / 2 块 GND 铺铜。
- 原理图 DRC：0 错误 0 致命错误，剩余 38 条聚合警告，类型为图元网格对齐、供应商编号标准化提示、主控未使用引脚未加非连接叉；不影响电气连接与制板。
- 板框闭合，100×80 mm 圆角矩形。
- Gerber 独立解压核对：共 15 个文件，含顶层/底层铜皮（GTL/GBL）、顶层/底层丝印（GTO/GBO）、顶层/底层阻焊（GTS/GBS）、板框（GKO）、PTH/NPTH/VIA 三个钻孔文件（Drill_PTH_Through.DRL、Drill_NPTH_Through.DRL、Drill_PTH_Through_Via.DRL）以及飞针测试数据。
- BOM 26 个物料行，SMT 坐标 58 行，与 PCB 器件数一致。

## 四、阻抗说明（如实说明）

本板 Type-C 只供电，D+/D- 未连接，板上没有 USB 数据链路，也没有 HDMI、以太网等高速差分信号，因此两层板不需要做 90Ω 差分阻抗控制，也未放 22Ω 串阻。全板最高频率为 8MHz 主晶振，走线已按常规短路径处理。

## 六、下单注意

1. 上传 Gerber 压缩包后系统会自动识别：2 层 / 100×80 mm / 1.6 mm，无需手工填层数。
2. 按老师要求自行焊接：下单时只选"PCB 打样"，不要勾选 SMT 贴片；元件按 `手焊物料清单.xlsx` 自行采购。
3. Type-C 母座为 16P 贴板式（C165948），焊接前先用万用表确认 VBUS 与 GND 不短路；R12/R13 两颗 5.1k 必须在 Type-C 上电前焊好，否则 CC 无下拉，部分充电器不会输出 5V。
4. 蜂鸣器 LS1 是 5V 有源蜂鸣器 TMB12A05，由 Q1 三极管驱动，不要装成无源蜂鸣器。
5. TF 卡座为推拉式（SD-47352-101），贴片时注意方向，丝印 1 脚有标记。
6. 红外模块用 GY-MCU90640（MLX90640），I2C 模式：PS 脚接 GND 后重新上电，共 5 根线。
7. 板上无 USB 转串口芯片，串口调试需外接 USB-TTL，接 J1 的 TX/RX。

## 七、已知限制

1. Type-C 供电入口未加专用 ESD/TVS 器件（原 D2 USBLC6 已随数据线一起删除），插拔靠 F1 与板级布局保护；若长期频繁插拔，建议下一版补一颗 TVS。
2. 电源支路存在局部线宽不足 20 mil 的情况：主干为 20 mil，芯片引脚附近分支为 10~12 mil，DRC 通过，常规电流下可用。
3. 底层丝印内容很少，绝大部分丝印在顶层，属正常。
4. 屏幕用 2×17 排母直插，装配时注意排母高度和外壳开窗。
5. 本板为毕业设计验证板，未做 EMC 认证测试。
6. 2D/3D 预览图为 EDA 内截图，仅用于展示外观与走线，实际加工以 Gerber 文件为准。
