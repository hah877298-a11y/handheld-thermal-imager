# 功能 1 联调验收记录（MLX90640 实时温度读取）

- 日期：2026-10-03
- 硬件：正点原子精英板 STM32F103ZET6 + GY-MCU90640 模块（PS 接 GND，I2C 直通模式）
- 固件：bit-bang 软件 I2C（PB6=SCL/PB7=SDA）+ 官方算法移植，刷新率 4Hz
- 观测手段：串口 115200 每帧统计（Ta/min/max/mid）+ LCD 同屏显示

## 一、验收数据

### 1. 对墙（室温基准）

```
F=7921 Ta=37.2 min=29.0 max=34.1 mid=30.9
F=7929 Ta=37.2 min=29.2 max=33.8 mid=31.5
F=7937 Ta=37.3 min=29.1 max=32.5 mid=31.4
```

- min/max ≈ 29~34°C，与室温（~30°C）一致，整帧温差 ≤4°C → **达标**
- 注：手持传感器致 FOV 边缘混入手部热辐射，温差略大属操作因素

### 2. 热水杯（高温，近沸腾热水，陶瓷杯壁，复测）

```
F=21137 Ta=36.5 min=32.8 max=52.0 mid=40.7
F=21153 Ta=36.5 min=34.3 max=73.9 mid=41.0
F=21161 Ta=36.5 min=34.9 max=72.4 mid=43.6
F=21169 Ta=36.5 min=29.3 max=32.0 mid=30.4   ← 传感器移开后
```

- max 稳定 70.0~73.9°C（水接近沸腾，杯壁隔热损失 10~15°C 属正常）；杯子占满视野时 min 升至 32.8~34.9（连"最冷点"都是杯壁）
- 移开传感器后 max 一帧内回落到 31.5~32.2°C（动态响应正确）
- 首次测量（~60°C 热水）max 45.8~47.2°C，同样达标 → **达标**（标准 max ≥ 40°C，理想 50~60°C，本次 70+ 更充分）

### 3. 冰块（低温，替代冰水混合物）

```
F=16905 Ta=35.9 min=0.8 max=12.5 mid=2.7
F=16921 Ta=35.7 min=0.7 max=16.1 mid=2.9
F=16945 Ta=35.8 min=1.0 max=30.4 mid=2.7
```

- min 0.7~1.3°C（冰点附近，物理上可信），中心像素 2.5~4.0°C
- max 随背景变化（手持移动）→ **达标**（标准 min ≤ 10°C）

## 二、联调中解决的关键问题（论文"系统调试"章节素材）

1. **Keil 烧录失败**（Target DLL cancelled）：Debug 选项停留在"Use Simulator"（做 NACK 路径验证时切换，未切回 ST-Link）
2. **code=-2（I2C 超时）**：逐级排查（引脚电平探针→寄存器转储→SWRST 复苏实验），确证板载硬件 I2C1 外设对 START 指令无响应（寄存器可读写、状态机不工作，疑似兼容片硅片缺陷）
   - 对策：`iic.c` 改为软件模拟 I2C（bit-bang），上层驱动 API 与错误码不变，**零改动迁移**
3. **code=-9（器件 ID 校验失败）**：根因为模块出厂处于 UART 模式（板载 MCU 干扰 I2C 总线）。查模块使用手册：**PS 接 GND + 掉电重启** 进入 I2C 直通模式；同时修正设计错误假设——EEPROM 0x240F 存的是 I2C 地址（手册示例 BE33 与实测一致），设备 ID1~3 在 0x2407~0x2409
4. **code=-8（撕裂帧）**：8Hz 帧周期 125ms < bit-bang 读帧 ~200ms，读帧跨越 RAM 刷新。刷新率降为 4Hz 后消失；功能 2 阶段提速 I2C 后可回 8Hz
5. **LCD 显示截断**：`LCD_ShowString` 宽度参数 200px < 温度字符串 224px 导致折行，改为 240px
