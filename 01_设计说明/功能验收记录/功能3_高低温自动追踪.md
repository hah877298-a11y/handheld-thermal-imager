# 功能 3 联调验收记录（高低温自动追踪）

- 日期：2026-10-05
- 硬件：正点原子精英板 STM32F103ZET6 + GY-MCU90640（PS 接 GND，I2C 直通模式）
- 固件：HARDWARE/TRACK（极值定位 + EMA 平滑）+ main.c 双色十字准心，-O2
- 观测：LCD 双色准心 + 串口 115200（1Hz 统计 + 渲染分段耗时）

## 一、验收结果（对照 spec 第 7 节 5 条，全部通过）

| # | 标准 | 结果 |
|---|---|---|
| 1 | 准心位置正确 | ✓ 白十字指向视野最高温区域、青十字指向最低温区域 |
| 2 | EMA 平滑无抖动 | ✓ 热水杯入画时白十字平滑滑向杯壁热点，约 0.5~1s 到位，无瞬移 |
| 3 | 双色可辨 | ✓ 白色=高温、青色=低温（铁红 LUT 无青色，辨识度极佳） |

| 5 | 帧率/性能 | ✓ 有效帧率 3.93Hz ≈ 4Hz，r=44ms（map 1 + interp 28 + fill 14），全程无 -8 |

移动目标测试：热源扫过画面时双准心实时平滑跟随，无高频抖动、无残影（旧准心由每帧全量热图重刷自然覆盖，无需擦除逻辑）。

## 二、实现要点（论文素材）

- **极值定位**：`Track_Find` 单遍扫描 768 点温度场，记录最高/最低点坐标（并列取先出现），复杂度 O(n)
- **平滑算法**：输出像素坐标一阶指数平滑 `s += 0.35·(t − s)`（EMA），4Hz 下时间常数 ~0.7s；首帧直接跳变避免从原点滑入
- **绘制**：LCD_Fill 细条画臂长 5px/线宽 1px 十字（规避该屏 DrawLine 缺陷）；准心钳制在热图区内
- **显示分离设计**：色带数值即时响应（响应优先）、准心平滑滑动（视觉稳定优先）
- **性能增量 <0.1ms**（768 次比较 + 4 浮点 + 4 次 LCD_Fill），帧预算零影响
- PC 测试：`test/pc_track/` 5 项（单峰/并列/均匀场/收敛性/单调无超调）PASS
