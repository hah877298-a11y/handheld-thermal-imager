# 功能 4 联调验收记录（按键切换调色板）

- 日期：2026-10-07
- 硬件：正点原子精英板 STM32F103ZET6 + GY-MCU90640（PS 接 GND，I2C 直通模式）
- 固件：HARDWARE/PALETTE 三调色板 LUT + 活动指针，KEY0 循环切换，-O2
- 观测：LCD 热图颜色 + 合并显示行 + 串口 115200

## 一、验收结果（对照 spec 第 6 节 5 条，全部通过）

| # | 标准 | 结果 |
|---|---|---|
| 1 | KEY0 循环切换铁红/彩虹/黑白，下一帧生效 | ✓ 三档循环，画面即时变色 |
| 2 | KEY1 切换插值模式（功能 2 能力保留） | ✓ 马赛克/平滑对比实验搬家成功 |
| 3 | 显示行正确 | ✓ `MODE:BILINEAR PAL:IRON` / `PAL:RAIN` / `PAL:GRAY` 同步更新 |
| 4 | 帧率/性能不变 | ✓ 有效帧率 3.93Hz，r=49ms（map 1 + interp 31 + fill 16），全程无 -8 |
| 5 | PC 测试全 PASS | ✓ 三表锚点/单调性/切换/映射 + interp/track 回归全过 |

实测串口（热水杯场景）：max 67~70°C 稳定追踪，F=1 即为干净数据（无启动垃圾帧）。

## 二、性能说明

r 从 44ms 增至 49ms（+5ms）：LUT 指针间接寻址（ColorizeStrip/色带查色走活动指针）+ 色带每帧 320 次函数调用。仍在帧预算内（200ms 读 + 49ms 渲染 = 249ms < 250ms），4Hz 保持。若后续功能需要余量，可把色带刷新改为"仅调色板/极值变化时重绘"（省 ~2ms）。
