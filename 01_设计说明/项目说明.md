# 基于 STM32 的手持红外热成像仪设计

基于 STM32F103ZET6 与 MLX90640 的手持红外热成像仪。传感器输出 32×24 温度点阵，经定点 Q8 双线性插值放大为 256×192 伪彩色热力图，支持高低温自动追踪、三种调色板切换、画面冻结与 SD 卡拍照、超温声光预警。

## 一、系统组成

| 部分 | 选型 | 说明 |
|---|---|---|
| 主控 | STM32F103ZET6（LQFP-144，72 MHz，512 KB Flash） | 自制主板上直接贴装，Keil MDK5 + 标准外设库开发 |
| 红外传感器 | GY-MCU90640 模块（MLX90640，32×24） | I2C 地址 0x33，PS 脚接 GND 后重新上电进入 I2C 直通模式 |
| 显示 | ATK-MD0280 2.8 寸 320×240 TFT | 并口 16 位数据，经 2×17 排母直插 |
| 存储 | 板载 TF 卡座（SDIO，FAT32） | 拍照保存 24bpp BMP |
| 时钟 | 8 MHz 主晶振 + 32.768 kHz RTC 晶振 | 主晶振配 22 pF，RTC 配 10 pF |
| 人机交互 | 4 个轻触按键、2 个 LED、5 V 有源蜂鸣器 | 蜂鸣器由 SS8050 三极管驱动 |
| 供电 | Micro-USB 5 V → 0.5 A 自恢复保险丝 → AMS1117-3.3 | 3.3 V 供主控与数字电路 |
| 保护与调试 | USBLC6-2SC6 ESD、1N4148、磁珠；5P SWD 接口 | 预留 2 组 4P 扩展 IO |

## 二、功能与实现

| # | 功能 | 实现要点 |
|---|---|---|
| 1 | 红外温度实时采集 | 软件 I2C 读取 MLX90640，移植官方 API 完成坏点修正与温度解算 |
| 2 | 热力图插值放大 | 定点 Q8 双线性插值，32×24 → 256×192，可与最近邻模式对比 |
| 3 | 高低温自动追踪 | 帧内极值搜索 + EMA 平滑，双色十字准心叠加显示 |
| 4 | 调色板切换 | 铁红 / 彩虹 / 黑白三套查找表，KEY0 循环切换 |
| 5 | 冻结与拍照 | WK_UP 冻结画面并写入 SD 卡 BMP，再按一次解冻 |
| 6 | 超温预警 | 阈值 50 °C 触发、48 °C 解除，施密特迟滞避免临界抖动 |

按键定义：KEY0 切换调色板，KEY1 切换插值模式，WK_UP 冻结 / 拍照。

## 三、主要指标

- 测温范围：-40 ~ 300 °C（MLX90640 量程），传感器分辨率 0.1 °C
- 有效帧率：约 3.9 Hz（串行读帧约 200 ms + 渲染约 47 ms，整帧 16 位并口刷屏）
- 主板尺寸：100 × 80 mm，双层板，板厚 1.6 mm，1 oz 铜厚，FR-4
- 固件规模：Code 58058 B / RO 8210 B / RW 152 B / ZI 25168 B，0 error 0 warning
- PCB：57 个元件、328 个焊盘、98 个过孔，DRC 0 错误 0 违规

## 五、编译与烧录

1. 用 Keil MDK5 打开 `03_固件工程/USER/ThermalImager.uvprojx`，直接 Build 即可，无需额外配置。
2. 编译输出在 `03_固件工程/OBJ/`（首次编译时自动生成）。
3. 烧录：ST-Link V2 接板上 J1 的 SWD 接口（3.3V / SWDIO / SWCLK / GND），或用 `04_烧录文件/ThermalImager_v1.2.hex` 直接下载。
4. 上电前确认 MLX90640 模块 PS 脚已接 GND，否则模块停留在串口模式，I2C 读不到数据。
